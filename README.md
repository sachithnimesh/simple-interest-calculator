# Simple Interest Calculator

This project provides a simple Bash script to calculate simple interest.

## Description

The Simple Interest Calculator computes the simple interest based on the following formula:

Simple Interest = (Principal × Rate × Time) / 100

## Features

- Calculates simple interest
- Easy to use
- Written in Bash

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/sachithnimesh/simple-interest-calculator.git
   ```

2. Navigate to the project directory:
   ```bash
   cd simple-interest-calculator
   ```

3. Make the script executable:
   ```bash
   chmod +x simple-interest.sh
   ```

4. Run the script:
   ```bash
   ./simple-interest.sh
   ```

## Formula

```
Simple Interest = (Principal × Rate × Time) / 100
```
